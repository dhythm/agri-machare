# Agri Machare — リブランディング設計

## ブランドの考え方

**農機具と、次の可能性を。**

農機具を所有する人、必要とする人、運ぶ人をつなぐ。購入・レンタル・レンタル購入を比較し、取引のやり取りから運搬の依頼まで同じ場所で進められるプラットフォームとして再構成した。

トップのメッセージは「農機の可能性を、次の畑へ。」。最初に目的を選んで検索でき、説明を読み終える前に自分の用事を始められる。

## 実装上の原則

- 認証・権限・API・データストアの契約は変えず、既存コンポーネントの情報階層と導線を整える。
- 出品者、借手、運搬者は同一アカウントで行き来できる。固定した役割別アカウントへ分断しない。
- 検索の条件やログイン前の農機情報を、次の画面で失わない。
- 審査フィルターの取得失敗は、表示データと選択済み条件を維持して結果内に通知する。
- 新しい検索導線、現在地表示、未読表示、運営検索、運搬の引継ぎ等はVitestで振る舞いを検証する。
- 未実装のエスクロー決済、メール通知、保証を実装済みとして案内しない。問い合わせと運搬応募の受付後はアプリ内の会話へ直接進める。

## 現在のサービス範囲

元のサービスはコンセプト検証版で、実決済は未実装。今回も本番決済やリース契約・定額請求、新規会員登録を追加していない。期間指定のレンタル、出品条件に応じた購入充当、取引メッセージ、運搬マッチングを実装済み機能として扱う。料金や出品のサンプルデータは変更していない。
